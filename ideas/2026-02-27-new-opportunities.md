## 🎯 Nieuwe Kansen

### 1. VendorSync - Event Vendor Coördinatie Platform
**Fit: ⭐⭐⭐⭐⭐ (EventShare synergie + WhatsApp-first + Excel-vervanger)**

#### Het Probleem
- **Vendor chaos:** Eventplanners coördineren 5-15 vendors per event (catering, AV, decoratie, fotograaf, DJ, locatie)
- **WhatsApp/Email jungle:** Alle communicatie verspreid over 20+ threads - "Wat spraken we af met de cateraar?"
- **Geen centrale timeline:** Vendor A denkt opbouw om 14:00, vendor B rekent op 15:00
- **Dubbele invoer:** Vendor details in Excel, communicatie in WhatsApp, facturen in Outlook
- **Blame-shifting:** Als iets misgaat, niemand weet wie verantwoordelijk was
- **Geen visibility:** Eventplanner weet niet of DJ zijn apparatuur al heeft gecheckt
- **Last-minute chaos:** Dag voor event - "Wie regelt de stoelen eigenlijk?"
- **Budgetoverschrijding:** Geen realtime zicht op kosten per vendor, pas achteraf schrikken
- **Documentatie verloren:** Contracten, verzekeringscertificaten, vergunningen verspreid over mails
- **Herhaald werk:** Zelfde vendors voor elk event, maar steeds opnieuw briefen

#### De Oplossing: "VendorSync"
**"Alle vendors, één dashboard - van offerte tot afrekening"**

**Core Features:**

- **Vendor Database:**
  - Centrale vendor-bibliotheek met contacten, prijzen, reviews, certificaten
  - Filter op type (catering, AV, fotografie), locatie, prijsklasse, rating
  - Vendor history: welke events, feedback scores, punctualiteit
  - One-click uitnodigen voor nieuw event

- **Event Command Center:**
  - Visueel timeline per event met alle vendors
  - Wie doet wat, wanneer, waar (drag & drop planning)
  - Afhankelijkheden: "DJ kan pas opbouwen als AV klaar is"
  - Milestones met deadlines en reminders
  - Checklists per vendor: "Heeft catering definitieve gastenlijst?"

- **Vendor Portal:**
  - Vendors krijgen eigen login (gratis voor hen)
  - Zien hun opdrachten, tijdslots, briefing
  - Uploaden: factuur, verzekeringsbewijs, equipment list
  - Markeren: "Opbouw voltooid" → eventplanner ziet real-time status

- **Communicatie Hub:**
  - Chat per vendor binnen platform (geen WhatsApp nodig)
  - Broadcast: bericht naar alle vendors tegelijk
  - WhatsApp/email forward-to-app (voor vendors die platform niet willen)
  - Audit trail: alle communicatie bewaard, doorzoekbaar

- **Budget & Financiën:**
  - Budget per vendor categorie
  - Offertes uploaden en vergelijken
  - Realtime spend vs budget dashboard
  - Factuurstatus tracking: ontvangen → goedgekeurd → betaald

- **Templates & Hergebruik:**
  - Event templates: "Bruiloft 100p" met standaard vendor rollen
  - Clone previous event: kopieer setup naar nieuw event
  - Briefing templates per vendor type

- **Dag-van-Event:**
  - Mobile app voor eventdag
  - Check-in vendors bij aankomst
  - Realtime issue logging
  - Snelle communicatie met alle vendors on-site

#### Waarom Nu
- **Events terug post-COVID:** Drukste eventseizoen ooit, veel nieuwe planners
- **Vendor schaarste:** Goede vendors zijn maanden van tevoren volgeboekt - relatiebeheer cruciaal
- **Hybrid events:** Meer vendors dan ooit (tech vendors erbij)
- **WhatsApp burnout:** Professionals zoeken structuur, niet nog meer groepen
- **Professionalisering:** Freelance eventplanners willen er "pro" uitzien
- **Excel fatigue:** "Ik heb 47 spreadsheets per event" - echte quote uit research
- **AI integratie:** Mogelijkheden voor AI-assisted planning en vendor matching

#### Marktgrootte
- **Eventplanners NL (freelance + bureau):** ~8.000
- **Locaties met eigen eventcoördinatie:** ~3.000 (hotels, kastelen, venues)
- **Bedrijven met regelmatige events:** ~5.000 (corporate events)
- **Primaire doelgroep:** ~10.000 gebruikers
- **Pricing:** €49-199/maand
- **SAM:** 10.000 × €100 gem. × 12 = **€12M/jaar** potentieel NL
- **België/Duitsland:** 3-4x groter
- **Upsell:** Vendor marketplace fees, premium vendors spotlight

#### Concurrentie
| Speler | Sterkte | Zwakte |
|--------|---------|--------|
| Honeybook | US-based, mooi design | Focus op freelancers, niet event-vendor specifiek |
| EventNest (nieuw) | AI-powered | Academic concept, nog geen product |
| Monday.com | Flexibel project mgmt | Generiek, niet event-specific, complex setup |
| Airtable | Krachtige database | Moet zelf bouwen, geen vendor portal |
| Excel + WhatsApp | Iedereen kent het | Chaos, geen audit trail, tijdrovend |
| Asana/Trello | Taakbeheer | Geen vendor-specifieke features |
| Plutio | All-in-one freelance | Niet NL, te breed, geen vendor portal |

**Blue Ocean Score: 8/10**
- Geen dominante NL/EU vendor-coördinatie tool voor MKB eventplanners
- Differentiatie: Vendor portal (two-sided) + NL-taal + EventShare integratie
- Risico: Big players (Monday, Airtable) kunnen features toevoegen
- Moat: Network effect - hoe meer vendors op platform, hoe waardevoller

#### Business Model
| Plan | Prijs | Doelgroep | Features |
|------|-------|-----------|----------|
| Starter | €49/maand | Freelance planner | 5 events/jaar, 10 vendors, basic timeline |
| Professional | €99/maand | Kleine bureau | Unlimited events, 50 vendors, budget tracking |
| Business | €199/maand | Event bureau | + Multi-user, vendor portal branding, API |
| Enterprise | Custom | Locaties/ketens | White-label, dedicated support, integraties |

**Vendor-side:**
- Gratis account: zie je opdrachten, basis profiel
- Premium vendor: €29/maand voor "verified" badge, analytics, leads

#### MVP Features
1. **Event aanmaken:** Basis info, datum, locatie
2. **Vendors toevoegen:** Contactinfo, rol, tijdslot
3. **Timeline view:** Visueel wie-wat-wanneer
4. **Vendor portal:** Simpele login om opdracht te zien
5. **Checklist per vendor:** Items aftikken
6. **Budget tracker:** Bedrag per vendor, totaal vs budget
7. **Export:** PDF voor locatie/client

#### Bouwtijd
- MVP: 6-8 weken
- V1.0 met vendor portal + communicatie: 12-14 weken
- V2.0 met budget + templates + mobile: 18-20 weken

#### Go-to-Market
1. **EventShare klanten:** Natuurlijke cross-sell - "nu ook je vendors managen"
2. **Freelance eventplanner communities:** Facebook groepen, LinkedIn
3. **Vendor partnerships:** Grote cateraars/AV-bedrijven promoten bij hun klanten
4. **"Vendor chaos calculator":** Hoeveel uur verlies je per event aan coördinatie?
5. **Template library:** Gratis event templates → lead magnet
6. **Wedding planner niche eerst:** Hoge vendor count, bereid te betalen

#### Synergies met Bestaande Projecten
- **EventShare:** Foto's + vendor coördinatie = complete event toolkit
- **HorecaMaster:** Cateraars als vendors, menu sync
- **GoldenDeal:** Deals van event-vendors promoten

#### Risico's
- **Two-sided marketplace:** Vendors moeten ook adopteren
- **WhatsApp comfort:** "Maar ik kan ze gewoon appen?"
- **Feature creep:** Risico om "everything app" te worden
- **Seasonality:** Events zijn seizoensgebonden → MRR fluctuatie

#### Mitigatie
- **Vendor incentive:** Gratis tool voor vendors, zij pushen bij planners
- **WhatsApp integration:** Forward messages naar platform, bridge bouwen
- **Focus:** Start met 1 use case (bruiloften) dan uitbreiden
- **Annual plans:** Korting voor jaarabonnement, stabielere revenue

### 2. AccessEvent - Event Toegankelijkheid Compliance Tool
**Fit: ⭐⭐⭐⭐ (Events expertise + Regulatie-gedreven = MUST-HAVE)**

#### Het Probleem
- **EU Accessibility Act (2025):** Nieuwe wetgeving eist toegankelijke diensten, inclusief events
- **Onwetendheid:** 73% eventplanners weet niet hoe ze events accessible moeten maken
- **Checklist ontbreekt:** "Moet ik een doventolk hebben? Rolstoeltoegankelijk? Rustige ruimte?"
- **Venue info onbekend:** "Is de locatie rolstoelvriendelijk?" - vaak niet gedocumenteerd
- **Communicatie ontoegankelijk:** Uitnodigingen/websites niet screenreader-compatible
- **Laatste moment paniek:** Gast belt dag voor event: "Ik ben slechtziend, wat is er geregeld?"
- **Geen register:** Welke aanpassingen heb je aangeboden? Geen audit trail
- **Subsidies gemist:** Er zijn subsidies voor toegankelijke events, maar onbekend
- **Reputatierisico:** Negatieve PR als event ontoegankelijk blijkt
- **Hybrid events:** Online component ook accessible? Ondertiteling? Gebarentolk?

#### De Oplossing: "AccessEvent"
**"Maak elk event toegankelijk - met een checklist, niet een consultant"**

**Core Features:**

- **Accessibility Audit Wizard:**
  - Stap-voor-stap vragenlijst: "Wat voor event? Hoeveel gasten? Indoor/outdoor?"
  - Output: Gepersonaliseerde accessibility checklist
  - Prioriteiten: Must-have vs nice-to-have per eventtype
  - Wettelijke vereisten highlighted

- **Venue Accessibility Database:**
  - Crowdsourced venue-informatie: rolstoeltoegankelijk? Inductielus? Parkeren?
  - Eventplanners vullen aan na events
  - Filter: "Toon alleen volledig rolstoeltoegankelijke locaties in Utrecht"
  - Venue reviews met accessibility focus

- **Communicatie Templates:**
  - Toegankelijke uitnodiging templates (WCAG-compliant)
  - Registratieformulier met accessibility-vragen: "Heeft u specifieke behoeften?"
  - Auto-reply met bevestiging aanpassingen
  - Website widget: "Dit event is toegankelijk voor..." badges

- **Resource Marketplace:**
  - Vindbare leveranciers: doventolken, ringleidingen, braille printing
  - Prijsindicaties en beschikbaarheid
  - Direct boeken of offerte aanvragen
  - Reviews van andere eventplanners

- **Accessibility Statement Generator:**
  - "Dit event biedt: rolstoeltoegankelijkheid, rustige ruimte, grote letters programma"
  - One-click genereren voor website/social
  - PDF voor print

- **Compliance Dashboard:**
  - Per event: welke accessibility features zijn geregeld?
  - Documentatie: bewijs voor audits/subsidies
  - Historisch: "Vorig jaar hadden we 3 dove gasten, dit jaar 5"
  - Rapportage voor organisaties met accessibility doelstellingen

- **Training Modules:**
  - Micro-learnings: "Hoe begeleid je een blinde gast?" (5 min)
  - Certificaat voor personeel
  - Disability awareness basics

#### Waarom Nu
- **EU Accessibility Act:** Juni 2025 van kracht - deadlines lopen
- **Inclusie-beweging:** Maatschappelijke druk op accessible events groeit
- **Subsidies beschikbaar:** Overheid stimuleert, maar aanvraag is ingewikkeld
- **Corporate ESG:** Bedrijven moeten rapporteren over inclusiviteit
- **Hybrid normaal:** Online events MOETEN accessible zijn (ondertiteling, etc.)
- **Reputatierisico:** Één virale klacht over ontoegankelijk event = PR-ramp
- **Regulatie = Must-have:** Zoals HACCP, wordt dit verplicht → verkoopt zichzelf

#### Marktgrootte
- **Eventorganisatoren NL:** ~15.000 (bureaus, freelance, corporate)
- **Locaties met events:** ~5.000
- **Compliance-bewust (doelgroep):** ~12.000
- **Pricing:** €39-129/maand
- **SAM:** 12.000 × €70 gem. × 12 = **€10M/jaar** potentieel NL
- **Overheid/semi-overheid:** Hoge compliance-druk → enterprise deals
- **België/Duitsland/EU:** Zelfde wetgeving, 10x markt

#### Concurrentie
| Speler | Sterkte | Zwakte |
|--------|---------|--------|
| AccessiWay | Website accessibility | Alleen digitaal, niet fysieke events |
| Consultants | Maatwerk, expertise | Duur (€500+/dag), niet schaalbaar |
| Checklists online | Gratis, beschikbaar | Generiek, geen tool, geen tracking |
| EventMobi | Event platform | Basic accessibility, niet core focus |
| Niemand specifiek | - | → Blue ocean! |

**Blue Ocean Score: 8.5/10**
- Geen dedicated event accessibility SaaS in NL/EU
- Differentiatie: Event-specifiek (niet alleen websites) + NL-wetgeving + venue database
- Risico: Niche kan te klein zijn, of grote spelers voegen toe
- Moat: Crowdsourced venue data + supplier netwerk

#### Business Model
| Plan | Prijs | Doelgroep | Features |
|------|-------|-----------|----------|
| Starter | €39/maand | Freelance planner | Audit wizard, checklists, templates |
| Professional | €79/maand | Bureau | + Venue database, supplier marketplace, compliance dashboard |
| Enterprise | €129/maand | Corporate/overheid | + Multi-user, rapportage, API, training modules |
| Venue | €49/maand | Locaties | Eigen accessibility profiel, badge voor marketing |

**Add-ons:**
- Supplier booking fees: 5-10% commissie
- Training certificaten: €29 per persoon
- Accessibility audit on-site: €299 (via partner-netwerk)

#### MVP Features
1. **Audit wizard:** Vragenlijst → gepersonaliseerde checklist
2. **Checklist tracker:** Per event afvinken welke items geregeld
3. **Accessibility statement generator:** Tekst voor website/social
4. **Basis venue info:** Handmatig toevoegen, zoekbaar
5. **Resource links:** Lijst met suppliers (geen marketplace nog)
6. **PDF export:** Compliance rapport

#### Bouwtijd
- MVP: 5-6 weken
- V1.0 met venue database + templates: 10-12 weken
- V2.0 met marketplace + training: 14-16 weken

#### Go-to-Market
1. **EU Accessibility Act urgentie:** "Deadline nadert - ben je klaar?"
2. **Overheidsinstanties:** Hoge compliance-druk, budget voor tools
3. **Event branche-organisaties:** Partnerships met IDEA, EventBranche
4. **Toegankelijkheidsorganisaties:** Samenwerking met Ieder(in), Visio, etc.
5. **LinkedIn thought leadership:** Content over event accessibility
6. **Gratis accessibility scan:** Analyseer je event → upsell tool
7. **Venue partners:** Locaties willen "Accessible Venue" badge

#### Synergies met Bestaande Projecten
- **EventShare:** Accessible foto-upload/viewing features
- **VendorSync:** Filter vendors op accessibility expertise
- **AnswerThis:** Ondertiteling/transcriptie voor seminars

#### Risico's
- **Niche te klein:** Hoeveel events focussen écht op accessibility?
- **Wetgeving vaag:** Als handhaving uitblijft, minder urgentie
- **Education needed:** Markt moet eerst leren waarom dit belangrijk is
- **Subsidie-afhankelijkheid:** Als subsidies stoppen, motivatie daalt

#### Mitigatie
- **Breed positioneren:** Niet alleen compliance, ook "betere events" value prop
- **Corporate focus:** ESG-rapportage dwingt actie af, ongeacht wetgeving
- **Community building:** Accessibility advocates als ambassadeurs
- **Start enterprise:** Overheid/grote bedrijven eerst, dan MKB

## 🔑 Aanbevelingen

### Prioriteit 1: AccessEvent
- **Regulatie-gedreven:** EU Accessibility Act = verplicht → verkoopt zichzelf
- **Timing:** Wetgeving net ingegaan, markt zoekt oplossingen
- **Simpeler model:** Geen two-sided marketplace nodig
- **Enterprise potentieel:** Overheid en grote bedrijven = hoge ACV
- **Thought leadership:** Positioneer als "accessibility expert" in events

### Prioriteit 2: VendorSync
- **Grotere markt:** €12M SAM, meer directe pijn (dagelijkse chaos)
- **EventShare synergie:** Perfecte upsell voor bestaande klanten
- **Network effect:** Als dit lukt, sterke moat
- **Complexer:** Two-sided marketplace vereist meer effort

### Strategische Overweging
VendorSync + EventShare + AccessEvent kunnen samen een **"EventPro Suite"** vormen:
- EventShare: Foto's delen en presenteren
- VendorSync: Vendor coördinatie
- AccessEvent: Toegankelijkheid compliance
- Bundle pricing: Complete event management toolkit
- Positioning: "Van planning tot afloop, één platform"
